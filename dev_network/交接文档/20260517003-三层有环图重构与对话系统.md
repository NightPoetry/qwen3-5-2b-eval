### 3. 三层有环图重构（v3 核心）

**问题**: 000 有 82 个 refs → 关键词冲突 + 光标续入碰运气。

**解决**: 三层结构。

```
Layer 1: 000 → [B00工程域, C00推理域, D00创作域, A00对话域]
Layer 2: 各域的 refs → 具体执行节点（原 82 个）
Layer 3: 执行节点 → 输出节点(Y10/Y20/Y30/Y40) → refs 回指域抽象
```

**新增 8 个节点**:
- A00 对话域 (regex中文, unless _domain_routed)
- B00 工程域 (技术关键词, unless _domain_routed)
- C00 推理域 (分析/推理关键词, 不含"为什么", unless _domain_routed)
- D00 创作域 (写/创作/诗, unless _domain_routed)
- Y10 对话输出 (key_exists _chat_response) → refs: [B00,C00,D00,A00]
- Y20 代码输出 (key_exists html) → refs: [B00,C00,D00,A00]
- Y30 分析输出 (key_exists _reasoning) → refs: [B00,C00,D00,A00]
- Y40 创作输出 (key_exists _creative_output) → refs: [B00,C00,D00,A00]

**引擎变更**: engine.py 的 check_trigger 加了 `unless` 守卫（3行）。当域节点设置 `_domain_routed` 后，其他域的 trigger 自动失败 → 每轮只有一个域激活。

**光标行为**:
- 哲学聊天后 cursor=[840, Y10, 890] → 下轮 Y10.refs 检查域 → A00 匹配 → 继续对话域
- 代码后 cursor=[..., Y20] → 下轮 Y20.refs → B00 匹配技术词 → 继续工程域
- 域切换: cursor refs 不匹配 → 回退 000 → 重新全量路由

### 4. 3D 可视化特效

- **光束飞行**: 消息发送后，光球从节点 A 射向节点 B，到达后粒子爆发激活
- **能量衰减**: 节点激活后渐暗（指数衰减），频繁激活的节点基底更亮
- **BFS 光波**: 长按节点，青色波纹沿 refs 方向 BFS 扩散；再按同节点，品红色反向 BFS
- 域抽象节点 = 菱形，输出节点 = 方块，普通节点 = 球
