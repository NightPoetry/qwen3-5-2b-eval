### 检索链路（渐进降级）

```
新检索
  │
  ├─ 0. 指针缓存命中? → O(1) 直接返回 (query_hash → 缓存结果)
  │     └─ 二次命中: 0.00s，不调 LLM
  │
  ├─ 1. 概括记忆匹配? → bigram 交叠 > 0.15 → 直接使用
  │
  ├─ 2. Bigram Top-7 分块检索
  │     └─ 用户追问("还有/继续") → Top-14 (跳过已展示)
  │
  ├─ 3. 继续追问 → 全盘扫描 → LLM总结 → 概括记忆 [0, N]
  │
  └─ 4. 概括被质疑("不对/不全") → 删除概括+指针 → 全扫
        └─ 无结果 → 确定性:"确定没有"
```

### Bigram 评分（替换关键词分词）

```python
def bigram_score(query, text):
    qb = bigrams(query)  # 字符级双字母组
    tb = bigrams(text)
    return len(qb & tb) / len(qb)  # 0.0~1.0
```

不依赖中文分词，中英文统一处理。比关键词匹配更鲁棒。

### 指针缓存

- 存储: `chat_logs/{sid}_pointers.json`
- 键: `md5(query)[:8]`
- 值: `{query, result, chunk_indices, access_count, created_at}`
- 超30条自动清理（按 access_count 排序，保留热数据）
- 概括被质疑时删除对应指针

### 数据文件

每个会话 3 个文件：
- `{sid}.json` — 聊天记录（最近 100 条）
- `{sid}_memories.json` — 概括记忆（最多 10 条）
- `{sid}_pointers.json` — 指针缓存（最多 30 条）

- 不遮挡内部节点

- 边线基础透明度 0.10 → 0.18，始终可见
- 边线颜色提亮 (0x060e1e → 0x0e1a2e)
