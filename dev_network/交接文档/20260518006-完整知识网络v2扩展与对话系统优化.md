## 架构关键点（新会话必须知道的）

### 引擎执行模型
```
用户输入 → 000(入口) → 域路由(A00/B00/C00/D00) → 子节点链 → 输出(Y10/Y20/Y30/Y40)
                              ↑                                        |
                              └──── 三级光标续入 ────────────────────────┘
```

### 三级续入
1. 工作节点续入：从 cursor 中非输出节点的邻接找 keyword 匹配
2. 域续入：找 `_active_domain` 域路由
3. 全局回退：回到 000

### 设计哲学（铁律）
- 所有语义判断用 LLM，不用正则/关键词
- 2B 单线程：每次 ask() 只问一个简单问题
- trigger 宁严勿宽
- 节点 = 可执行程序，不是被动知识
- 图中不能有死区（0 死胡同、0 孤立）
